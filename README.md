# DEX EDITS

Car, F1, football and movie edits for TikTok and YouTube Shorts, cut with code: every transition is snapped to the
real drum hits of the song (measured within one frame), every shot comes from its own take, and every edit tells
one story.

- `videos/` – finished edits
- `engine/` – the editing engine
- `EDITING_RULES.md` – how every edit is made
